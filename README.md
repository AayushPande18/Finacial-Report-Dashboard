# 📊 Financial Report Dashboard (Power BI)

## 📌 Overview

This project showcases an interactive **Financial Report Dashboard** built using Power BI to analyze key business metrics such as Profit, Revenue, Units Sold, COGS, and Gross Sales. The dashboard helps in understanding financial performance across multiple dimensions.

---

## 🔍 Features

* KPI cards for quick overview of business performance
* Profit analysis by **Product, Segment, and Discount Band**
* Year-wise profit comparison
* Identification of top-performing and loss-making areas
* Country-level filtering for focused analysis

---

## 📈 Key Insights

* Government segment generates the highest profit
* Enterprise segment shows a negative profit (loss)
* Paseo is the top-performing product
* Discount strategies significantly impact profitability

---

## 🛠 Tools & Technologies

* **Power BI** – Data visualization and dashboard creation
* **Power Query** – Data cleaning and transformation
* **DAX** – Calculations and measures

---

## 🎯 Objective

To convert raw financial data into meaningful insights that support **data-driven decision-making**.
